# 🚀 Performance Marketing Strategies for BHEL Jagdishpur

This repository contains my **Summer Training Project** completed at **Bharat Heavy Electricals Limited (BHEL), Jagdishpur**.

The project explores how **Performance Marketing**, **Digital Marketing**, and **Business Analytics** can be applied to a large Public Sector Enterprise (PSU) to enhance industrial marketing, B2B lead generation, and data-driven decision-making.

- Industrial Marketing Analysis
- Performance Marketing Framework
- Business Analytics
- B2B Marketing Strategy
- Marketing KPIs & ROI
- Strategic Recommendations
